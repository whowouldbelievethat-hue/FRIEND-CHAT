# Friends Chat v2

نسخة مطوّرة من Friends Chat بواجهة عربية RTL متجاوبة.

## المميزات الموجودة في الكود
- إنشاء حساب وتسجيل دخول عبر Firebase Authentication.
- ملف شخصي: اسم عرض، اسم مستخدم، نبذة، وصورة شخصية.
- البحث عن مستخدم وبدء محادثة خاصة.
- إنشاء مجموعات وإضافة أعضاء بأسماء المستخدمين.
- محادثات فورية باستخدام Cloud Firestore.
- رسائل نصية، رد على رسالة، تعديل رسائلك النصية، حذف منطقي، وتفاعلات.
- إرسال صور وملفات حتى 15MB عبر Firebase Storage.
- تسجيل رسالة صوتية من الميكروفون وإرسالها.
- حالات نصية أو صور تنتهي بعد 24 ساعة.
- بحث في قائمة المحادثات وفلتر غير المقروءة والمجموعات.

## تشغيله
1. أنشئ مشروعًا من https://console.firebase.google.com/
2. فعّل Authentication > Sign-in method > Email/Password.
3. أنشئ Cloud Firestore Database.
4. فعّل Storage.
5. من إعدادات مشروع Firebase أضف تطبيق Web وانسخ `firebaseConfig`.
6. افتح `index.html` واستبدل القيم `YOUR_API_KEY` و`YOUR_PROJECT`... بإعداداتك.
7. انشر محتوى `firestore.rules` في Firestore Rules، ومحتوى `storage.rules` في Storage Rules.
8. ارفع مجلد المشروع على استضافة HTTPS مثل Firebase Hosting أو افتحه عبر خادم محلي.

## تنبيهات مهمة
- لا تترك قواعد Firestore/Storage مفتوحة للعامة.
- تسجيل الصوت يحتاج إذن الميكروفون وHTTPS أو localhost ومتصفحًا يدعم MediaRecorder.
- هذا إصدار دردشة ويب تجريبي قابل للتشغيل بعد إعداد Firebase، وليس تطبيق WhatsApp رسميًا.
- لا توجد مكالمات صوتية/مرئية أو تشفير طرف إلى طرف في هذا الإصدار.
- يفضّل إضافة Cloud Functions للتحقق من أسماء المستخدمين بشكل ذري ومنع انتحال/تكرار أسماء المستخدمين، وإضافة قواعد تحقق أشد للرسائل والملفات قبل استخدامه على نطاق واسع.
